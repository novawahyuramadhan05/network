# Network Engineering Simulation Projects

This repository contains a collection of simulation-based projects focused on core concepts in network engineering. The goal is to build practical understanding of how data moves, is routed, and behaves under different network conditions.

Instead of relying only on theoretical study, each concept is implemented through simplified simulations to develop engineering intuition.

---

## Core Focus Areas

### 1. Packet Behavior
Understanding how data is broken into packets and transmitted across a network.

Key concepts:
- Packet structure and flow
- Transmission delay (latency)
- Packet loss behavior
- TCP vs UDP fundamentals

---

### 2. Routing & Network Topology
Understanding how data chooses paths across interconnected nodes.

Key concepts:
- Network graphs
- Routing logic
- Hop-by-hop communication
- Shortest path behavior (conceptual)

---

### 3. Performance Analysis
Understanding how network performance is affected under different conditions.

Key concepts:
- Bandwidth limitations
- Throughput vs latency trade-offs
- Network congestion
- Queueing delay

---

### 4. System-Level Behavior (Future Expansion)
Understanding how large-scale networks behave under load.

Key concepts:
- Multi-node systems
- Traffic simulation
- Scalability behavior
- Bottleneck analysis

---

## Projects in This Repository

### 1. Packet Flow Simulator
Simulates how packets move from a client through routers to a server, including delay and packet loss.

### 2. Routing Simulation Model
Simulates how data selects optimal paths in a network using graph-based structures.

### 3. Network Performance Analyzer
Analyzes how bandwidth, latency, and congestion affect overall network performance.

---

## Learning Approach

Each project follows a simple engineering model:

Input → Processing → Network Behavior → Output Visualization

The focus is not on production-level systems, but on understanding core networking principles through simplified models.

---

## Tech Stack (for simulations)

- Python
- NumPy (for numerical simulation)
- Matplotlib (for visualization)
- NetworkX (for graph-based modeling, optional)
